# Hotel Marseille Roadmap

## Stage 1 - Working private version

Goal: replace the Excel workflow with a private web app that can already be used by the hotel.

Included:
- GitHub repository for version control.
- Vercel deployment.
- Supabase database for rooms and stays.
- Private login for one hotel user.
- Dashboard with occupancy, arrivals, departures, and debt summaries.
- New stay form with guest, room, dates, color, payment split, and notes.
- Records page with filters and edit flow.
- Calendar view with room occupancy and date selection.
- Room inventory page.

## Stage 2 - Operational improvements

Possible next improvements after the first version is tested:
- Better reporting by period, payment type, and debt.
- Export to Excel or CSV.
- Multiple staff users and roles.
- Activity history for changes.
- Cleaner mobile/tablet layouts if staff use phones.

## Stage 3 - Localization and advanced workflow

Future improvements if needed:
- Georgian language.
- Russian language if the hotel asks for it.
- Guest document/photo attachments.
- Invoice templates.
- Notifications and reminders.
- More detailed room management.
